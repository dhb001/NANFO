# ADR-018: Remaining Operator Workflow Integration

- Status: Accepted for explicit user request to implement remaining Step 12 features
- Date: 2026-09-10

## Scope

Add measured probe-path evidence, integrated frozen-model diagnostic inference,
immutable versioned operational/training configuration, persistent timed overrides
and verified restoration with gated return. Preserve historical models/training
sources and current manual execution safety. Do not equate experimental model
qualification with calibrated production autonomy. No new websocket channel.

## Approved Surfaces

All APIs use existing success/data/meta/errors envelopes and current membership/
permissions. Read requires read:telemetry; writes require write:config and
execute:rollback plus current writable organization membership.

- GET `/api/v1/autonomy/configuration?network_id=UUID`: effective operational revision,
  immutable revision history, requested training settings and retraining state.
- PUT `/api/v1/autonomy/configuration`: network_id, expected_revision, reason,
  operational:{max_observation_age_seconds,decision_interval_seconds,
  min_route_hold_seconds,max_changes_per_minute}, training:{reward_weights}.
  Fixed finite bounds; changes cannot weaken calibrated safety or enable autonomy.
  Runtime operational settings are applied by the Autonomy worker; reward changes
  remain requested/retraining_required, never mutate running frozen model weights.
- GET `/api/v1/autonomy/model?network_id=UUID`: operator-allowlisted pinned model
  metadata/status and recorded inference diagnostics, never caller filesystem paths.
- POST `/api/v1/autonomy/model/diagnose`: network_id and operator-provisioned history
  reference ID. Run restricted checkpoint/history validation and frozen inference
  in a bounded separate process. Persist action/probabilities/value/model/input hashes
  and timings/provenance. Historical inference is clearly historical and cannot
  dispatch. Missing compatible live history reports unavailable, not fake data.
- GET/POST `/api/v1/autonomy/overrides`: scoped list; create network_id,intent_id,
  execution_id,expected_revision,reason,duration_seconds,return_mode. Adopt only
  a verified active manual execution owned by this actor/network and persist its
  exact command identity. Hold mode=monitor during override. Approval is explicit,
  bounded to duration/model/prior revision; STOP cannot be cleared by expiry.
- POST `/api/v1/autonomy/overrides/{id}/cancel`: expire early; idempotent with scoped
  current permission checks. It requests restoration, not immediate success.
- POST `/api/v1/autonomy/overrides/{id}/return`: fresh explicit mode-return request
  after verified restoration and revision/current-approval checks. Model/observer/
  safety/executor unavailable means return_blocked and monitor, not fake activation.
- GET `/api/v1/telemetry/paths?network_id=UUID`: bounded recent observed probe paths
  with run, packet ID, timestamps, ordered observed hops, completeness, freshness,
  evidence hash and contrast against approved configuration where available.

## Ownership and Durability

Autonomy owns immutable configuration revisions, model diagnostic records and timed
override lifecycle via migration0015 after0014. Use locks/CAS and one active override
per network. The independent worker handles expiry/retry, never browser timers.
Exact-owned recovery has server authority only to compensate an enrolled execution,
even after original actor revocation; new execution remains denied. Intent owns
the restricted restoration method and actual durable cancellation/readback; do not
impersonate the original user or create a generic auth bypass. Store prior mode,
model, actor/reason/expiry, hashes, cancellation ID, attempts and verified outcome.
Concurrent STOP/revision changes dominate automatic return. Uncertain restoration
keeps exclusion and exposes diagnostics, not successful expiry. All outbox/events
reuse documented existing lifecycle names or stay REST-polled; no invented events.

## Measured Path and Model Boundaries

Telemetry owns bounded read-only ingestion of an operator-allowlisted probe-path
artifact. Container-local capture correlates actual per-interface packet/probe IDs
and ordered hops, exports atomic versioned data without DB credentials. Backend
uses trusted DPID/device binding and rejects stale/mixed-run/ambiguous/missing-hop
claims. Path means observed selected probe during its measured window, not all
application flows or a currently active path indefinitely. Partial/multipath/order
uncertainty is explicit. No trace generated by copying planned route names.

Frozen model registry is operator-provisioned outside producer-writable directories,
pins checkpoint/source/history hashes; no uploaded pickle or arbitrary executable.
Inference subprocess uses fixed configured interpreter/entrypoint, restricted load,
no network/control access, bounded input/output/time/concurrency. Probabilities are
not safety confidence. Recorded evaluation/inference is useful operator evidence,
not continuous-observer compatibility or automatic promotion.

## Verification

Test config revision conflicts/retraining distinction and actual worker use;
override expiry/restart/concurrency/actor revocation/STOP/failed restoration/gated
return; strict model allowlist/tampering/fresh inference replay; actual captured
probe path with tenant binding plus partial/stale cases. Run disposable real DB/
HTTP/worker and isolated lab tests, no shared-service reset. UI exposes all real
states, accessible charts/path/timing, countdowns and failures. Retain residual
production autonomy gates honestly; no feature is complete from metadata alone.
