# Debug Workflow

**Description:** A structured sequence to debug issues with minimal scope and regression risk.

1. Reproduce the issue and capture exact symptom(s).
2. Collect logs, traces, and failing inputs.
3. Identify owning module and boundary crossings.
4. Form a root-cause hypothesis backed by evidence.
5. Implement the smallest safe fix.
6. Add or update regression tests.
7. Validate architecture/security/testing guardrails.
8. Document cause, fix, and residual risks.
