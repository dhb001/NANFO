# Refactor Workflow

**Description:** Improve structure and readability without changing behavior.

1. Define explicit non-functional refactor scope.
2. Identify duplication and complexity hotspots.
3. Preserve public interfaces and contracts.
4. Apply incremental, reviewable changes.
5. Run relevant tests and add missing regression coverage.
6. Verify no behavior or API drift.
7. Document tradeoffs and follow-up opportunities.
