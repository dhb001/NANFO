# NANFO Project Constitution

## 1. Vision & Mission
* **Vision:** To become the world’s most intelligent, vendor-neutral, AI-powered Digital Twin platform capable of autonomously understanding, simulating, optimizing, and evolving enterprise network infrastructures.
* **Mission:** Unify Software-Defined Networking, Multi-Agent AI, 3D Spatial Digital Twins, predictive network physics, and autonomous intent orchestration into an explainable decision-support platform.

## 2. Core Engineering Philosophy
* **Everything is Data & Has an Ontology:** All entities inherit from a centralized Universal Object Model (UOM).
* **Modular Monolith First:** Subsystems communicate strictly through internal Event Bus contracts.
* **Absolute Explainability:** No black boxes; every AI output mandates supporting evidence, metric traces, and confidence ratings.
* **Simulation Precedes Production:** Mandatory validation in the Network Physics Engine before physical execution.
* **Safe Autonomy:** Policy-driven confidence gates enforce human-in-the-loop governance.

## 3. Universal Rules & Formatting Safeguards
* **PlantUML Formatting:** Always preserve strict structural line breaks so they are not accidentally stripped out during browser copy-paste actions to external editors.
* **UAT Documentation:** When generating automated User Acceptance Testing (UAT) sheets, explicitly fill in all empty fields in the 'actual results' column with required validation data rather than leaving them blank.
