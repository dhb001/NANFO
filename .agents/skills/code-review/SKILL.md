# Code Review Skill

When reviewing code for NANFO, follow these steps:

## Review checklist
1. **Architecture Boundaries**: Does the code break the modular monolith rules?
2. **Explainability**: Are AI predictions returning supporting evidence?
3. **Correctness**: Does the code do what it's supposed to?

## How to provide feedback
* Be specific about what needs to change.
* Explain why, not just what.
* Suggest alternatives when possible.
