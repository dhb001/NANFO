# Security Skill

## When to use
- Any change touching auth, permissions, input processing, or sensitive data.

## Checklist
- Input validation and sanitization preserved.
- Secrets never hardcoded or logged.
- Least-privilege and RBAC enforced.
- Audit trail requirements satisfied.
