# AIOS Skill

## When to use
- Agent behavior, recommendation quality, or autonomy policy design.

## Checklist
- Explainability includes rationale and evidence.
- Confidence thresholds are policy-aligned.
- Human approval path is clear where required.
- Memory usage and context boundaries are explicit.
